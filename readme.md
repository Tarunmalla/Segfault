## Installation
To get started with this project, follow these steps:
1. Clone the repository: `git clone https://github.com/tarunmalla/segfault.git`
2. Navigate to the project directory: `cd segfault`
3. Install Neccessary dependencies mentioned below as follows
    - `pip install django`
    - `pip install django_restframework`
    - `pip install pillow`

4. Now do the necessary migrations and run the website which can be done as follows:
    - `python manage.py makemigrations`
    - `python manage.py migrate`
    - `python manage.py runserver`
